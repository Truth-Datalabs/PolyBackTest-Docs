## Overview

PolyBackTest maintains high-frequency **Polymarket prediction-market data** with
Chainlink reference prices. API access to collected history is plan-based: the
default window is **31 days**, and Pro users can select **60-day**, **120-day**,
or **150-day** historical-data access. Storage retention and the API query
entitlement are separate: buying a longer window does not create, restore, or
backfill observations that were never collected or are no longer retained.

<Info>
Dedicated/Enterprise plans remain at up to 120 days. Shared Pro's 150-day option
starts at **$59.90/month for 10 RPS**. Existing 31-, 60-, and 120-day subscriptions
keep their purchased terms and can choose an upgrade from the Dashboard.
</Info>

<Note>
A 150-day entitlement sets the maximum query window for the key. It does not
create data from before collection began. Until all backfills are verified, the
oldest available timestamp may vary by coin, market type, or individual market.
</Note>

<Info>
v4 endpoints take the coin as a required query parameter (`?coin=btc`). Supported coins are `btc`, `eth`, and `sol`.
</Info>

## Polymarket Up/Down Markets

Historical prediction market data for crypto up/down markets (BTC, ETH, SOL).

| Metric | Value |
| :--- | :--- |
| **Stored Coverage** | Varies by coin, market type, collection start, retention, and gaps; not guaranteed by the plan window |
| **Default API History Window** | 31 days |
| **Extended API History Windows** | 60, 120, or 150 days (shared Pro); up to 120 days (Dedicated/Enterprise) |
| **Markets Tracked** | 5,000+ |
| **Total Snapshots** | 60,000,000+ |
| **Snapshot Frequency** | 8 Snaphots per second per market |
| **Market Types** | 5m, 15m, 1h, 4h, 24h |
| **Data Captured** | Prices, order books, crypto price (BTC, ETH, SOL) |

### Data Sources & Accuracy

**Crypto Prices (BTC, ETH, SOL)**
- **Every supported timeframe (5m, 15m, 1h, 4h, 24h)**: Tracked via **Chainlink** reference prices and stored without synthetic winner-price replacement.

**Market Resolution**
- PolyBackTest aligns its reference-price history with the Chainlink inputs used by supported Polymarket markets.

**Data Consistency**
- **Orderbooks**: Captured directly from the market - fully consistent.
- **Resolution Data**: Uses official resolution data - settlement outcomes are accurate.
- **Price Accuracy**: Chainlink integration keeps reference data aligned with the settlement source.
